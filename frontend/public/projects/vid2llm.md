# vid2llm

vid2llm turns a public video link into text an AI agent can read: author, description, stats and a timestamped transcript. Agents pay per video with x402 in USDC, from one cent, with no account and no API key. It works with TikTok, YouTube, Instagram and X, over plain HTTP or as an MCP server.
